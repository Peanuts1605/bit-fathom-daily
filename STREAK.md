# Streak rules (Bit & Fathom Daily Riddle)

Kid-friendly default:

1. **Playing today counts whether the answer is right or wrong.** A wrong guess does not punish the streak; it still marks the day as played.
2. **Only one streak change per local calendar day** — the first time you answer today's riddle.
3. **Archive (past) riddles never change the streak.**
4. **Skipping a local day resets the streak to 0 on the next visit** (before you play again). Best streak is kept.
5. **Dates use the device's local calendar** (`getFullYear` / `getMonth` / `getDate`), so the mapped riddle is stable across timezones and DST.

After the first 14 days, riddles loop and an **Encore** badge is shown.
